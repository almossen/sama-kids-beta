# عالم سما للأطفال — نسخة اختبار خاصة

تضم هذه النسخة صفحة البداية، ثماني مغامرات مصوّرة ومسموعة، ولعبتي «مفاتيح الطاقة» و«طريق سما». يبدأ الموقع من `index.html`، وجميع الصور والأصوات مدمجة في صفحات HTML.

الغرض من هذا المستودع مشاركة نسخة اختبار مع عدد محدود قبل ربطها بالمنصة الرئيسية. لا تضع بيانات الأطفال أو ملاحظات المراجعين الشخصية في المستودع. للاستخدام على استضافة ثابتة، ارفع محتويات هذا المجلد كما هي؛ تفاصيل الربط النهائي في `README_DEPLOY_AR.md`.

المصدر القابل لإعادة البناء محفوظ محليًا في مشروع سما، أما هذا المستودع فيحتوي على **حزمة العرض الجاهزة** فقط.
