# عالم سما للأطفال — نسخة اختبار للمشاركة

تضم هذه النسخة صفحة البداية، ثماني مغامرات مصوّرة ومسموعة، ولعبتي «مفاتيح الطاقة» و«طريق سما». يبدأ الموقع من `index.html`، وجميع الصور والأصوات مدمجة في صفحات HTML.

هذه نسخة الاختبار النهائي بتاريخ 25 سبتمبر 2026، مبنية على التعديلات المقدمة في `sama_kids_v3_final.zip`. أُضيفت المقاطع الصوتية السبعة الناقصة، وتحسينات التنقل في المغامرة الأولى، وتجميع المغامرات في الصفحة الرئيسية. فُحصت الصفحات العشر وروابطها وصورها وصياغة JavaScript، وجُربت على مقاس هاتف وآيباد.

الغرض من هذا المستودع مشاركة نسخة اختبار مع عدد محدود قبل ربطها بالمنصة الرئيسية. **المستودع ورابط GitHub Pages عامّان**؛ مشاركة الرابط مع أشخاص محددين لا تقيّد الوصول تقنيًا. لا تضع بيانات الأطفال أو ملاحظات المراجعين الشخصية في المستودع. للاستخدام على استضافة ثابتة، ارفع محتويات هذا المجلد كما هي؛ تفاصيل الربط النهائي في `README_DEPLOY_AR.md`.

المصدر القابل لإعادة البناء محفوظ محليًا في مشروع سما، أما هذا المستودع فيحتوي على **حزمة العرض الجاهزة** فقط. يُنصح بالاستماع النهائي للمقاطع الجديدة واختبار الرابط مع عدد محدود قبل النشر العام.
