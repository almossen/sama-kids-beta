# ربط عالم سما للأطفال بالمنصة الرئيسية

هذه حزمة صفحات ثابتة مستقلة. ارفع محتويات هذا المجلد إلى المسار `/kids/` على استضافة `t1d-ar.com`، بحيث تُفتح `index.html` عند زيارة `https://t1d-ar.com/kids/`.

أضف في المنصة الرئيسية رابطًا إلى `/kids/` بعنوان «مغامرات سما للأطفال». روابط العودة إلى المنصة الرئيسية والتواصل موجودة في تذييل عالم سما. عبارة المراجعة الطبية في المنصة مبنية على تأكيد صاحب المشروع أن مختصًا راجع جميع المغامرات. الصور والصوت مدمجان في صفحات HTML؛ لا تحتاج الحزمة إلى خادم تطبيق أو مفاتيح خدمة.

بعد الرفع، راجع المغامرات الثماني واللعبتين على هاتف وآيباد، واختبر الصوت عبر HTTPS. قد يمنع المتصفح تشغيل المقدمة تلقائيًا؛ يظهر حينها زر لإعادة تشغيلها.
